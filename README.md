# 点击按钮 · Click the Button

[打开游戏 / Play](https://kkzky.github.io/click-the-button-web/)

这里存放可运行的静态网页文件。每次点击获得 1 分，支持中英文和浏览器本地存档。页面中的试玩链接固定对应一个游戏版本。

This repository contains the built website. Each click earns one point. Chinese and English are supported, with progress saved in your browser. Version links keep their original game build.
